Guarda cada imagen en esta carpeta y nombra el archivo con el ID del producto
que devuelve /api/productos, seguido de la extension .jpg.

Formato:
  <ID-del-producto>.jpg

Recomendaciones:
  - Usa imagenes JPG de 800 x 600 pixeles (proporcion 4:3).
  - El nombre distingue mayusculas/minusculas; usa el ID exacto y .jpg.
  - No uses el nombre del plato como nombre de archivo.
  - Si agregas productos nuevos, consulta su ID en /api/productos y crea
    el archivo con ese ID. Por ejemplo, si el ID es 21, usa 21.jpg.
  - Si una imagen no existe, la tarjeta mostrara el icono de su categoria.

Nota:
  Esta carpeta esta en los recursos estaticos del proyecto. Cuando se agregue
  la carga de imagenes desde el panel de administracion, se definira una
  ubicacion persistente para esas imagenes subidas.
